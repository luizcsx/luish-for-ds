A complete operating system for productivity, creation, and editing for the **Nintendo DS**.

## Overview

Luish is an alternative textual and graphical environment built specifically for the Nintendo DS hardware. Instead of competing with traditional desktop operating systems, Luish focuses on turning the handheld console into a portable productivity suite, leveraging the dual-screen layout and touch screen capabilities.

## Planned Features

* **Writing Pad**: A lightweight text editor for creating and modifying files directly on the SD card.
* **Calculator**: A built-in calculator utilizing the touch screen for efficient input.
* **Luish File Manager**: An intuitive file manager to browse, organize, and read system directories.
* **Terminal Mode**: A command-line interface mode for system navigation and utilities.

## Hardware Utilization

* **Top Screen:** Reserved for system status, clock, calendar, and active file viewing.
* **Bottom Screen:** The interactive workspace, featuring touch controls, virtual keyboard, and application inputs.

## Compilation

This project is configured to compile automatically using GitHub Actions. The build workflow generates the final `.nds` executable without requiring a local devkitPro installation.
