# Contributing to Luish

Thank you for your interest in contributing to Luish.

This project is an experimental operating system environment for the **Nintendo DS** focused on productivity, creativity, and portable tools.

## Goals

Contributions should help improve:

- Performance
- Stability
- User experience
- Accessibility
- Code readability
- Nintendo DS compatibility

## Before Contributing

Please:

- Read the README
- Check existing issues before opening new ones
- Keep pull requests focused and minimal
- Use clear commit messages
- Test changes whenever possible

## Code Style

General guidelines:

- Keep code modular
- Avoid unnecessary dependencies
- Prefer readability over complexity
- Document important functions
- Keep Nintendo DS hardware limitations in mind

## Pull Requests

When submitting a pull request:

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Commit clearly
5. Open a pull request with a detailed description

git checkout -b feature/new-file-browser
